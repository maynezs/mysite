Текстобой v2.2

Универсальный офлайн-редактор: Word (.docx) с точным отображением и настоящим экспортом, Markdown с живым предпросмотром, PDF-просмотр и редактор кода с подсветкой синтаксиса. HTML открывается как код с изолированным просмотром страницы. Все файлы обрабатываются локально — ничего не отправляется на сервер.

Возможности

  • Word: точный вид файла, лист A4, экспорт .docx
  • Markdown: сплит-режим, GFM, экспорт MD / HTML / DOCX
  • HTML и код: Python, JS, CSS, Swift и ещё 20+ языков
  • PDF: просмотр, масштаб, извлечение текста
  • PWA: установка на домашний экран, офлайн-режим

Горячие клавиши

Ctrl+S сохранить Ctrl+O открыть Ctrl+N новый документ Alt+W закрыть файл Ctrl+F найти Ctrl+H заменить в коде Ctrl+G перейти к строке Ctrl+E вкладка «Экспорт» Ctrl+P печать / PDF
