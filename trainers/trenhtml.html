📖 Справочник по HTML

💡 Шпаргалка по базовым тегам. Можно открывать во время теста — это не считается подсказкой, но ответ всё равно нужно ввести самостоятельно.
<!DOCTYPE html>
Объявление типа документа. Всегда первая строка HTML-файла. Указывает браузеру, что это HTML5.
<html>
Корневой элемент страницы. Внутри него находятся <head> и <body>.
<html> <head>...</head> <body>...</body> </html>
<head>
Служебный раздел. Содержит <title>, <meta>, <link>. Пользователю не виден.
<title>
Название страницы — отображается на вкладке браузера. Располагается внутри <head>.
<title>Мой сайт</title>
<body>
Тело документа. Всё видимое содержимое страницы находится здесь.
<div> / <span>
<div> — блочный контейнер (занимает всю ширину, переносит строку). <span> — строчный контейнер (внутри текста).
<div class="card">...</div> Цена: <span class="price">100 ₽</span>
<h1> … <h6>
Заголовки. <h1> — самый крупный, <h6> — самый мелкий.
<h1>Новости</h1> <h6>Сноска</h6>
<p>
Абзац текста. Браузер автоматически добавляет отступы между абзацами.
<p>Привет, мир!</p>
<br>
Перенос строки. Одиночный тег (закрывающий не нужен).
Строка 1<br>Строка 2
<hr>
Горизонтальная разделительная линия. Одиночный тег.
<strong> / <b>
<strong> — важный текст (жирный + смысл). <b> — просто жирный, без смысла.
<em> / <i>
<em> — смысловой акцент (курсив). <i> — просто курсив.
<u> / <s>
<u> — подчёркнутый текст. <s> — зачёркнутый текст.
<sup> / <sub>
<sup> — верхний индекс (степень). <sub> — нижний индекс.
E = mc<sup>2</sup> H<sub>2</sub>O
<code> / <pre>
<code> — фрагмент кода (моноширинный). <pre> — сохраняет пробелы и переносы.
<blockquote>
Блочная цитата с отступом.
<ul>
Маркированный (ненумерованный) список. Внутри — пункты <li>.
<ul> <li>Яблоко</li> <li>Груша</li> </ul>
<ol>
Нумерованный список. Пункты автоматически нумеруются.
<ol> <li>Первый</li> <li>Второй</li> </ol>
<li>
Отдельный пункт списка. Используется и в <ul>, и в <ol>.
<table>
Корневой тег таблицы.
<tr>
Строка таблицы (table row).
<td>
Обычная ячейка таблицы с данными.
<th>
Ячейка-заголовок: жирный текст и выравнивание по центру.
<caption>
Подпись к таблице (заголовок). Указывается сразу после <table>.
colspan / rowspan
Атрибуты объединения ячеек: colspan="2" — по горизонтали, rowspan="2" — по вертикали.
<table> <tr><th colspan="2">Заголовок</th></tr> <tr><td>1</td><td>2</td></tr> </table>
<form>
Контейнер формы. Атрибут action — адрес обработчика, method — способ отправки (get/post).
<form action="/send" method="post">...</form>
<input>
Однострочное поле ввода. Вид задаётся атрибутом type: text, password, checkbox, radio, submit и др.
<input type="text" name="login"> <input type="password" name="pass"> <input type="checkbox"> <input type="submit" value="Отправить">
<textarea>
Многострочное поле ввода. Парный тег.
<textarea name="msg" rows="5"></textarea>
<button>
Кнопка. Может содержать разметку внутри.
<button type="submit">Отправить</button>
<select> / <option>
<select> — выпадающий список, <option> — пункт списка.
<select name="city"> <option>Москва</option> <option>Санкт-Петербург</option> </select>
placeholder / name
placeholder — серая подсказка внутри поля. name — имя поля для отправки на сервер.
<a>
Гиперссылка. Адрес задаётся атрибутом href. target="_blank" — открыть в новой вкладке.
<a href="page.html">Перейти</a> <a href="https://site.ru" target="_blank">Сайт</a>
<img>
Изображение. Одиночный тег. src — путь к файлу, alt — текст-замена.
<img src="cat.jpg" alt="Кот">
<video>
Видео. Атрибут controls добавляет панель управления.
<video src="clip.mp4" controls></video>
<audio>
Аудио. Также поддерживает controls.
<audio src="song.mp3" controls></audio>
<link>
Подключение внешних ресурсов, чаще всего CSS-файла. Внутри <head>.
<link rel="stylesheet" href="style.css">
<header>
Шапка страницы или раздела. Не путать с <head> (служебный раздел).
<footer>
Подвал страницы: копирайт, контакты, ссылки.
<nav>
Блок навигации со ссылками.
<main>
Основное содержимое страницы. На странице должен быть один.
<aside>
Боковая панель: реклама, примечания, второстепенные ссылки.
