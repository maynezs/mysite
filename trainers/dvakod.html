ДВОИЧНОЕ КОДИРОВАНИЕ

Двоичный код — это способ представления информации с помощью двух знаков: 0 и 1.

Двоичный алфавит

Алфавит из двух знаков (символов) — 0 и 1. Слова из одного символа: «0» и «1». Из двух: 00, 01, 10, 11. Количество возможных слов вычисляется как 2n, где n — количество символов в слове.

Кодирование текста

Каждому символу (букве, цифре, знаку) ставится в соответствие уникальный двоичный код. В компьютерах обычно используется 8-битный код (1 байт = 8 бит). Это позволяет закодировать 256 различных символов.

Алгоритм кодирования:

  • Найти символ в кодовой таблице.
  • Записать соответствующий ему двоичный код.

Декодирование: Разбить код на группы по 8 символов и заменить каждую группу на символ из таблицы.

Графическая информация

Растровое изображение — совокупность точек (пикселей). Каждый пиксель имеет свой цвет, который кодируется двоичным числом.

Векторное изображение — состоит из геометрических фигур (отрезков, окружностей). Запоминается как набор команд для построения.
