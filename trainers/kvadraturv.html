Квадратный тренажёр

📘 Теория за 5 секунд

Уравнение: ax² + bx + c = 0 (a ≠ 0).
Дискриминант: D = b² – 4ac.
• Если D > 0 — два различных корня: x₁,₂ = (–b ± √D) / (2a).
• Если D = 0 — один корень (два равных): x = –b/(2a).
• Если D < 0 — действительных корней нет (в тесте таких не будет).

💡 Подсказка: нажми на синий кружок «?» рядом с уравнением — увидишь дискриминант.

Все корни в тесте — целые числа. Ответы записаны как «x₁, x₂» (например «-2, 5»).
