📘 ТЕОРИЯ (КОРОТКО)

  • Определение: √a = b, если b ≥ 0 и b² = a. Под корнем не может быть отрицательного числа.
  • Вынесение множителя: √(a²·b) = a·√b, например √72 = √(36·2) = 6√2.
  • Внесение множителя: a·√b = √(a²·b), например 3√5 = √45.
  • Действия: √a · √b = √(ab); (√a)² = a при a ≥ 0.
  • Уравнение √x = a имеет решение x = a² (при a ≥ 0).
  • Уравнение √(x + b) = a: возводим обе части в квадрат → x + b = a² → x = a² − b.
